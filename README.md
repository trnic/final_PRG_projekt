# Football Training Analyzer

Jednoducha webova aplikace pro analyzu fotbaloveho treninku.

## Spusteni

Otevri soubor `index.html` v prohlizeci.

## Soubory

- `index.html` - struktura stranky
- `style.css` - vzhled aplikace
- `data.ts` a `data.js` - typy treninku a ukazkova data
- `main.ts` a `main.js` - logika aplikace

V prohlizeci se spousti JavaScript soubory. TypeScript soubory zustavaji v projektu jako citelny zdroj s typy.
